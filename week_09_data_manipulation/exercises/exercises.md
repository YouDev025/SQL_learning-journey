# Week 9 Exercises

1. Write an INSERT statement for a `products` table.
2. Update a row in the `customers` table using `UPDATE`.
3. Delete rows where `status` is `inactive`.
4. Describe when to use `ROLLBACK`.
5. Write a bulk INSERT with at least three rows.
