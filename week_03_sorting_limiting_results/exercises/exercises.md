# Week 3 Exercises

1. Select all products sorted by `name` ascending.
2. Return the top 3 most expensive items from `inventory`.
3. Use `OFFSET` to skip the first 5 rows in a query.
4. Select unique values from the `category` column.
5. Write a query with column aliases for `first_name` and `last_name`.

---
Concepts (roadmap summary):
- Order results with `ORDER BY`
- Limit output using `LIMIT` and `OFFSET`
- Remove duplicates with `DISTINCT`
