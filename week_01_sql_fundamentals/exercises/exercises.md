# Week 1 Exercises

1. Write a query to select `id`, `name`, and `email` from a table called `users`.
2. Select all columns from a table called `orders`.
3. Write a query to select the `title` and `author` from `books`.
4. Create a simple `CREATE TABLE` example for a `categories` table with `id` and `name`.
5. Explain the difference between `VARCHAR` and `INTEGER` in one sentence.
