# Week 2 Exercises

1. Select rows from `employees` where `department` is `Sales`.
2. Select customers with `country` equal to `Canada` and `status` equal to `active`.
3. Find products where the `name` starts with `A`.
4. Select orders where `shipped_date` is NULL.
5. Write a query that returns rows where `price` is between 10 and 50.

---
Concepts (roadmap summary):
- Control query results with `WHERE`
- Use logical operators (`AND`, `OR`, `NOT`)
- Apply pattern matching with `LIKE` and `IS NULL`
